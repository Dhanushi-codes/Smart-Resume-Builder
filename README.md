# ✨ Smart Resume Builder

An AI-powered modern resume builder with live preview and downloadable PDF support.

## 🚀 Features

- Beautiful modern UI
- Multiple resume templates
- Live resume preview
- PDF download support
- FastAPI backend
- Responsive design
- Easy customization

## 🛠 Tech Stack

### Frontend
- HTML
- Tailwind CSS
- JavaScript

### Backend
- FastAPI
- Python

## ▶️ Run Locally

### Clone Repository

```bash
git clone https://github.com/Dhanushi-codes/Smart-Resume-Builder.git
```

### Install Dependencies

```bash
pip install fastapi uvicorn
```

### Run Backend

```bash
uvicorn main:app --reload
```

Open:
```text
http://127.0.0.1:8000
```
